# Experiment CT

## Purpose

Convert research into testable hypotheses.

## Constraints

- Each hypothesis must define independent variable, dependent variable, control, and metric.
- Include at least one negative or failure case.
- Define what result would falsify the hypothesis.
- Produce an experiment harness under `experiments/{topic-id}/`.
- Run `score-run.py` at least once for the current condition.
- Produce `results.jsonl` and `analysis.md`.
